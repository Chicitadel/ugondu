# Adapter: Node Ecosystem
# Location: .governance/ci/adapters/NodeAdapter.md

## Purpose
The `NodeAdapter` acts as a thin translation layer for JavaScript/TypeScript repositories (like `certify`). It takes the standard outputs from tools like `npm`, `jest`, and `eslint`, and maps them into the canonical `Governance Semantics v2.x` YAML schema.

## Translation Logic

### Tests
* **Source:** `jest-results.json`
* **Action:** Parses the number of passed/failed tests. If `failed > 0`, sets `tests.unit.status = failed`.
* **Governance Enforcement:** NONE. The adapter only translates the result. It does not decide if a failure is acceptable.

### Build
* **Source:** Exit code of `npm run build` or Vite compiler.
* **Action:** Translates `0` to `success`, `>0` to `failed`.

### Checksum
* **Source:** Evaluates the `dist/` or `build/` directory generated by Node.
* **Action:** Generates SHA256 and maps to `artifacts.checksum`.
