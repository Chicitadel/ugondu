# MATURITY MODEL

**Governance Status:** FROZEN
**Version:** 1.0.0
**Classification:** Enterprise Standard

The maturity progression governs the lifecycle of all platform capabilities within the Air Roofers ecosystem.

## Stages
1. **IC (Implementation Complete)**: Parallel execution streams successfully merged against a frozen control plane.
2. **IC2 (Integration Candidate)**: End-to-end integration boundaries verified against neighboring domains.
3. **RC (Release Candidate)**: Operational scenarios successfully simulated representing real-world operator workflows.
4. **PV (Production Validation)**: A formal **30-day observation window**. GA promotion requires explicit demonstration of sustained reliability based on concrete metrics:
   - Uptime / Availability
   - Mean Time To Recovery (MTTR)
   - Deployment Success Rate
   - Rollback Frequency
   - Incident Rate
   - ASI Stability
   - Documentation Drift
   - API Compatibility
5. **GA (General Availability)**: Full operational endorsement. Platform capabilities are deemed inherently stable.
