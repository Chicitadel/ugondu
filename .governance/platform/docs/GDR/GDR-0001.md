# Governance Decision Record: GDR-0001
**Title:** Immutable Evidence Taxonomy and Dual-Dimension Scoring
**Date:** 2026-07-17
**Status:** Accepted

## Reason
The execution framework matured to the point where 100/100 scores were being granted to capabilities (`ingestion`, `bootstrap`) based on simulated or mocked evidence outputs (e.g., `pytest`, `flake8` mocks) to unblock parallel migration streams. A perfect score resting on simulated evidence masks operational risk. Additionally, the decision engine required structural isolation from evidence generation.

## Impact
1. **Evidence Taxonomy Introduced:** All validation artifacts must declare explicit provenance (`Executed`, `Imported`, `Simulated`, `Manual Review`).
2. **Dual-Dimension Scoring:** The Certification Engine now computes an **Aggregate Confidence Index** independent of the **Compliance Score**. A capability may reach 100% Compliance but explicitly display a low Confidence Index if validations are mocked.
3. **Declarative Policy Packs:** Governance rules are evaluated against predefined capability classes (UI, API, System) to prevent rigid, one-size-fits-all denominator inflation.
4. **Operational Readiness Review (ORR):** A final, distinct gate was added to verify infrastructure prerequisites exclusively, separating deployment readiness from codebase quality.

## Migration
Existing execution outputs for `ingestion.airroofers.eu` and `bootstrap.airroofers.eu` have been retroactively recalibrated in the Evidence Registry to reflect `<100%` Confidence indexes while preserving their `100%` Compliance scores to allow migration progression.
