# DEPENDENCY REGISTRY

**Governance Status:** FROZEN
**Version:** 1.0.0
**Classification:** Enterprise Standard

## Dependency Auditing
For every capability in the Platform Catalog, the following metadata MUST be recorded to objectify dependency audits:
- Dependencies Declared
- Dependencies Actually Consumed
- Dependency Direction (Must be downwards)
- Version Constraints
- Lifecycle Stage (IC/RC/PV/GA)
