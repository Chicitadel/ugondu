# Air Roofers — mandatory universal execution governance

For every task, command, audit, implementation, remediation, feature, release qualification or continuation in this workspace:

1. Before planning or editing, load and follow the complete canonical policy:
   `https://raw.githubusercontent.com/Chicitadel/airroofers.eu/master/.governance/policies/AR-GOV-EXEC-001-Universal-Execution-Lifecycle-Policy.md`
2. Treat it as mandatory cross-product execution procedure for AIRROOFERS-COR, KEYBOARD-COR and every current or future Air Roofers product.
3. Preserve the invoking prompt exactly. This rule supplements it; it does not rewrite or replace product-specific requirements.
4. Discover and reuse existing policies, constitutions, scripts, guardrails, implementation plans and evidence. Do not create duplicate or conflicting controls.
5. Dispatch independent workstreams to dedicated subagents concurrently where supported, with explicit ownership and dependency controls. Create task-level plans and execute ready tasks while other audits continue.
6. Resolve blockers progressively; keep unblocked work moving; report each blocker and verified unblock to the lifecycle lead/continuation owner.
7. Enforce no-bypass, regression prevention, independent verification, commit-specific evidence and accurate release status.
8. If the canonical policy cannot be loaded, stop code-changing execution and report the access failure. Do not silently proceed without it.

This is an invocation adapter, not a competing policy. The central policy is the single normative source.
