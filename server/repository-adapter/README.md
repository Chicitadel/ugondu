# Ugondu Repository Adapter

## Purpose
The Repository Adapter abstracts the storage layer for Ugondu, providing standard interfaces for fetching and storing configurations and artifacts.

## Structure
- `src/index.ts`: Main adapter implementation and entrypoint.
- `dist/`: Compiled JavaScript output.
- `Dockerfile`: Container build definition.
